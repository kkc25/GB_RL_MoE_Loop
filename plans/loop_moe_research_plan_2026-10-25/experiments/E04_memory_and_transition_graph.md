# E04：路径记忆、转移图与充分状态诊断

**优先级 P1；是主线机制检验，不预设历史一定有益。**

## 问题与已有边界

[MoUE](https://arxiv.org/abs/2603.04971) 已有轻量轨迹状态的Universal Router，[Path-Constrained MoE](https://arxiv.org/abs/2603.18297) 已研究路径结构。因此仅增加transition matrix或GRU不构成充分创新。

检验：在同一个冻结骨干、同一成本监督目标、相同可用输入与参数预算下，显式m_t是否带来稳定增益？增益来自遗漏预算/轮数、输入压缩、有限函数类、还是实际序列互补？

## 对照层级

| 编号 | 输入/结构 | 消除的混杂 |
|---|---|---|
| H0 | h线性头 | 仅作弱参考 |
| H1 | h,t,budget，同大小MLP | 核心无历史对照 |
| H2 | h,t,budget，扩大MLP至与历史版等参数 | 控制函数容量 |
| M1 | H1 +上轮所选集合multi-hot | 一阶转移 |
| M2 | H1 +累计专家调用计数、重复次数 | 无序历史 |
| M3 | H1 +16/32维GRU记录有序动作 | 有序记忆 |
| M4 | MoUE机制的逐token因果轻量轨迹状态改编 | 已有机制对照 |
| N1 | H2+同维度随机/固定无关字段 | 额外通道对照 |
| O1 | h0、当前h、t,budget，等参数头 | 历史是否仅恢复初始输入信息 |

M4不是原文fast-weight轨迹状态的逐项复现，逐token因果接口是本实验的受控改编。所有模型都知t与remaining_budget。history按请求×token×层初始化，不允许跨文档残留。m编码过去已执行的动作与合法观测，不包含y、未执行专家输出或未来路由。

## 两个具体模型

**转移图：**8×8矩阵A，上一轮Top-2 multi-hot或权重p_{t−1}形成偏置 \(p_{t−1}^TA\)。分数为 `base_score(h,t,budget)+history_bias`，之后仍Top-2。允许自环；A不预设专家语义。使用L2小正则候选{0,1e-4}。

**价值记忆：**共享专家ID embedding（8×16），每轮将两专家embedding对称聚合后输入GRU32；成本网络输入h,t,budget,m。控制器总参数预算调整到H2一致（误差≤1%）；激活/推理时间也记录。不要仅匹配总参数却让历史版做更多在线专家计算。

## 实施步骤

1. 直接复用E02固定骨干、候选与Q^{π0}标签，避免额外数据差异。
2. 首先H1/H2/M1/M2四个廉价头；只有观察有序历史疑似有益才加M3/M4。
3. 固定100k/20k/20k文档分组状态起点、最多10epochs、两档lr与完全相同早停规则。
4. 评估静态predictor regret和真实on-policy NLL；非基准轨迹新状态按同一固定tail-policy重新标注。
5. 在相同t、budget、来源、h尺度分组内分析增益；强行把不同t的history交换会制造假收益。
6. 检查m能否线性预测原本漏掉的t/预算/输入摘要；若是，修补无history baseline后重新比较。
7. 仅在冻结结果成立后，可用相同小预算联合训练Router与专家，判断记忆是否促成额外分工；该结果另表。

## 严格干预与限制

- 完整控制状态相同而历史不同的自然碰撞通常难找；不能仅凭“两个浮点h近似相等”证明充分性或信息增益。
- E08用人为构造可验证状态做确切同状态反例；LM实验以预测增量和条件分组为经验结论。
- shuffle history会产生从未到达的(h,m)组合，性能下降只表明模型依赖历史，不自动证明历史带来额外信息。
- 同样，要区分错误历史破坏了控制器与正确历史胜过同容量无历史头。
- 图的某条边权大不等于“专家A负责逻辑、B负责语法”；专家置换可能保留行为，语义需额外任务证据。

## 泛化评估

在合成任务中预先留出一组有序操作组合，训练只覆盖其短子序列，测试组合长度/组合次序变化。报告任务正确率与路由收益；不要求真实专家与程序操作一一对应。

自然语言只按训练路径频率分桶作描述；由于路径由模型学习而非外生标签，“未见路径”选择可能受模型性能影响，不能直接宣称组合泛化因果证明。

## 资源、成功与失败

只训练小头，1卡；三卡做独立seeds。复用标签的增量预算上限为骨干1%，先用CPU或单GPU快速训练基线。

成功条件：相对H2仍有持出部署NLL提升，且超出参数/预算/轮数混杂；有序M3还应超过无序M2，才支持顺序记忆必要。

若H1补齐t、budget后历史增益消失，删去历史组件并保留这一诊断结果。若M1已达到M3效果，选M1；若O1达到M3，贡献更可能是恢复被压缩输入，不应描述成长期专家协作的证明。

输出：等容量头对比、状态字段消融、轨迹频率/转移图、跨任务组合结果、不可解释/无增益案例。
