# E03：收益校准的自适应停止

**优先级 P1；可独立于路径规划；只在多个深度均已训练可用时实施。**

## 研究问题与新颖性边界

能否在有限预算下预测“继续比现在停止的净收益”，且真实停止后保持质量？ACT、PonderNet、[MoR](https://arxiv.org/abs/2507.10524) 与 [TaH2](https://arxiv.org/abs/2609.35748) 已覆盖自适应深度/停止。[LatentHarness](https://arxiv.org/abs/2609.39740)也把EXIT与其他潜在动作一起反事实监督。本方案的贡献候选仅是与多步专家价值、校准误差和实际成本共同研究。

MoR的确切版本/链接以文献地图为准；实现机制对照时需复核原算法，不把泛称halt gate写成完整复现。

## 定义与目标

在末层状态s，stop输出Head(h)，停止成本
\(Q(s,stop)=E[\ell(Y,Head(h))\mid s]\)。
继续动作的成本采用E02的冻结π0续算，包含额外计算λc。比较

\[
\Delta(s,a)=E[\ell_{stop}-\ell_{continue(a,\pi_0)}\mid s],\qquad
\text{continue iff }\max_a\{\widehat\Delta(s,a)-\lambda\hat c(s,a)\}>\tau.
\]

第一版固定后续路由，只学停止；第二版才同时选a。成本ĉ必须与Δ对应同一条续算路径的全部剩余执行成本，不能用终局收益只扣下一步费用。固定π0的Q可用于每步重新决策和提前停，这属于策略改进，标签并非因此失效；数据聚合补足新策略到达状态的覆盖，tail仍保持π0。若改用新停止策略作tail，需另开策略迭代版本并重标。τ=0且满足理论误差条件才直接引用2Hε；保守τ≠0需加入相应逐步选择松弛项。

## 数据与可执行训练

1. 使用E00随机深度骨干，固定专家。对同一状态同时算stop和继续后的终局CE；标签只在训练/验证使用。
2. 从各t均衡采样100k状态起步；最终评估保留自然深度分布，不人为平衡测试。
3. 输入h,t,remaining_budget，初版不加完整词表熵，避免熵head成本掩盖收益；熵基线本身必须执行对应head。
4. 小MLP输出Δ及可选成本，平方损失回归（Huber仅作为改变统计目标的稳健性消融）；另训练二元继续标签作为对照。连续值便于跨λ调预算。
5. 在独立calibration split上选λ/τ，目标平均循环轮数为{1.5,2,3,4}，对应Top-2专家调用数{3,4,6,8}；若控制器不能精确达到某预算，报实际值并在曲线上插值，不篡改调用数。
6. 单独holdout验证校准：按预测Δ分箱，比较实际配对CE改善均值。选择保守阈值可以依据校准分箱误差，但不得把启发式不确定性写成逐样本概率保证。
7. 冻结阈值后评测最终test；换文本来源/上下文长度/请求batch测试预算漂移。

## 对照与消融

| 方案 | 控制信息 | 要计入的额外执行 |
|---|---|---|
| 固定R1/R2/R3/R4 | 无 | 固定调用 |
| entropy / max-prob阈值 | 完整词表预测 | 每轮head和softmax |
| logit-margin阈值 | 前2词表logit | 获得这些logit的实际实现成本 |
| hidden-change阈值 | ||h_t−h_{t−1}|| | 归约 |
| 仅h,t小MLP | 隐状态 | 小head |
| lookahead-supervised stop | 有监督收益标签 | 标签构建成本 |
| 路径价值+stop | E02动作价值 | 控制器28动作打分 |
| history+stop | 记忆 | 额外状态与更新 |

固定深度模型与随机深度模型都要有各自固定深度结果；随机深度训练造成的质量变化不能全部归给停止。

## 硬预算与安全退出语义

这里“硬”指计算上限，不涉及外部安全保证。每token有remaining expert calls，Top-2继续必须余量≥2；预算为0强制stop。默认最少一轮，Tmax4。已经停止的token不能因后续价格变化重新激活。

多请求global budget交给E07；本实验先不对同一序列未来token排序分配。若每一层均有停止，使用每层账本和全token账本，而非相互独立超预算。

## 评价

主表同时列：NLL/PPL；平均和p95循环；专家调用数；head次数；总forward FLOPs；actual tokens/s和p50/p95单步延迟；controller耗时；末层提前停止率。

末层方案R4→R1整网算术最多约8%改善，故“平均循环下降30%”不能写成“推理下降30%”。E03只在末层证明质量—调用权衡；整网效率见E11。

停止容忍起点为相对固定R4 NLL增加≤0.005 nat/token；若同FLOPs下质量更优也可成功。低估收益会过早停，高估收益会浪费计算，两类错误分开报告。

## 资源与触发规则

1卡即可；共享E02探针状态时重用标签但不重用test做训练。训练控制器最高5epochs/100k状态起点；标注预算≤骨干5%，不必重复完整预训练。三卡用于seeds。

- R1已与R4同质量：优先固定R1，停止器没有存在必要。
- R4持续变差：回E08修稳定性，不以停止掩盖坏循环。
- 熵基线与价值同样好：保留更便宜者，不能宣称路径记忆必要。
- 动态稀疏执行比固定深度慢：尝试分桶执行；仍慢则报告算术节省而不主张时延优势。

输出：校准曲线、质量—预算前沿、强制预算测试、跨域预算漂移表、控制开销profile。
