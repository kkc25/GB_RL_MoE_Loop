# 反例、排除标准与实验中必须检查的伪收益

核验截止：2026-10-25。以下小例子是本次为研究设计构造或复算的数学例子；没有执行真实 LLM 训练。数值部分已经在 CPU 上计算，结果保存在 `verified_toy_calculations.json`，可用同目录脚本重算。

## C1. 状态转移是 Markov，不代表隐藏状态对预测目标充分

令输入 \(X\in\{0,1\}\) 等概率，目标 \(Y=X\)。初始隐藏状态包含 \(X\)。第一轮路由按照 \(X\) 选择专家 \(E_X\)，而两个专家都把输出置为 \(h_1=0\)。于是两类输入的当前隐藏状态完全相同，历史 \(m_1=E_X\) 却保留了 \(Y\)。下一轮有两个动作，分别输出类别 0 或类别 1。

如果控制器只见 \(h_1\)，任何确定性分类的错误率都是 1/2；如果看历史，则可以零错误。所有专家转移仍然是当前 \(h\) 和动作的确定函数。这里破坏的是“目标/停止损失的条件分布由 \(h\) 充分决定”，不是转移 Markov 性。

**检验意义：**若真实模型中的路径记忆有效，应进一步判断它是恢复输入信息、补足系统状态，还是改善有限控制器的表示。不能只凭转移形式就说历史绝无价值，也不能只凭加入记忆后精度提升就声称发现非 Markov 计算。

**相反的阴性对照：**固定同一输入与全部非历史状态，把两段历史强行替换，在未来专家函数、合法动作和成本都不读历史时，给相同未来动作序列，输出必须相同。如果不同，代码存在未记录状态，或“历史交换”同时改了其他变量。

## C2. 标签可见 oracle 可以显示巨大利益，而真实路由完全不可学

输入 \(X\) 不携带关于 \(Y\sim\mathrm{Bernoulli}(1/2)\) 的信息。两个专家分别输出类别 1 的概率 0.99 和 0.01。另有直接输出 0.5 的停止动作。忽略调用成本。

| 策略 | 期望 NLL，单位 nat |
|---|---:|
| 看见真实标签后选专家 | −log(0.99) = 0.01005034 |
| 无标签时固定选任一极端专家 | −[log(0.99)+log(0.01)]/2 = 2.30761026 |
| 无标签时停止并输出 0.5 | log(2) = 0.69314718 |

Oracle 看起来比停止改善约 0.6831 nat，但任何只看 \(X\) 的策略都不能利用随机标签。允许混合输出也不能突破 Bayes 风险 log(2)。

**排除标准：**若 oracle 收益大而 held-out 标签盲的动作价值预测器持续不能恢复收益，先归因于不可预测性或特征不足；不要继续加深在线路径搜索，因为在线搜索同样看不到标签。增加基础模型训练或更换价值监督目标，比增加博弈复杂度更合理。

## C3. 价格更新可以永远振荡，平均平衡也会掩盖每轮拥塞

两个 token、两个专家，每个专家容量 1，两个 token 的两个专家原始得分都相等。每个 token 同步选择“得分减价格”最大者，平局选 A。价格更新为

\[
\pi_e^{k+1}=[\pi_e^k+(L_e^k-1)]_+.
\]

从 \(\pi^0=(0,0)\) 出发：

| 轮次 | 本轮价格 | 两个 token 的选择 | 负载 | 更新后价格 |
|---|---|---|---|---|
| 0 | (0,0) | (A,A) | (2,0) | (1,0) |
| 1 | (1,0) | (B,B) | (0,2) | (0,1) |
| 2 | (0,1) | (A,A) | (2,0) | (1,0) |

之后重复。每轮都超载 1，但两轮平均负载恰好满足容量。减小固定步长仅缩放价格差，等分数、同步 hard argmax 的例子仍能振荡。

**工程含义：**硬容量使用排队、分组 dispatch、可行匹配、overflow 重分配或降级停止保障；价格负责改善选择。不能用平均负载曲线代替逐 batch 容量验证。软路由、随机打破平局、滞后更新和有限次数局部修正是可以测试的缓解方式，不是未经证明的收敛结论。

## C4. Nash 均衡、势函数最优和社会最优是三个概念

### C4a. 严格均衡可能不是全局势最优

两个 token 的价值为

\[
V=\begin{pmatrix}4&5\\5&4\end{pmatrix},
\quad c_A(1)=c_B(1)=0,
\quad c_A(2)=c_B(2)=10.
\]

分配 (A,B) 的总价值和势函数都是 8。任何一个 token 独自切换后收益从 4 降为 −5，因此它是严格 Nash 均衡。两者同时交换成 (B,A) 时，势函数与总收益都变为 10。局部改进被协调障碍卡住。

### C4b. 全局势函数最优仍可能不是社会成本最小

两个同质 token，A 的延迟 \(c_A(k)=k\)，B 的延迟恒为 \(c_B(k)=2.5\)，没有额外价值差。两人都选 A 时，每人延迟 2，总延迟 4；单人转到 B 的延迟变为 2.5，所以 (A,A) 是均衡。

拥塞势成本为：AA=1+2=3，AB=1+2.5=3.5，BB=2.5+2.5=5。因此 AA 也是全局势成本最小。但 AB 的真实总延迟仅为 1+2.5=3.5，小于 AA 的 4。

**含义：**“我们有势函数”不证明模型性能或设备延迟最优。必须说明势函数对应哪个可观测目标，并报告均衡 gap、容量、真实 NLL 与真实 latency。经典原始文献自身已区分均衡和全局势最优。[Rosenthal 原文](https://ranger.uta.edu/~weems/NOTES6319/PAPERSONE/rosenthal1973.pdf)；[Potential Games](https://library.fa.ru/files/Shapley4.pdf)

## C5. 一步收益指数可能错过必须连续投入的路径

两个独立 token 的连续两次调用收益如下，成本均为 1，总预算为 2：

| token | 第一次收益 | 第二次收益 | 两次累计收益 |
|---|---:|---:|---:|
| A | 0.1 | 9.9 | 10.0 |
| B | 6.0 | 0.0 | 6.0 |

一步贪心先给 B，再给 A，累计 6.1。最优把两次都给 A，累计 10。若 A 的第一步暂时增加损失，差距还会更明显。

**实验意义：**用这个小环境检验两步价值控制器确实能恢复延迟收益。自然语言模型中是否存在同样的结构，需要反事实测量；不能把高预测熵直接解释为高追加计算收益。若不存在稳定的两步增益，选择一步 \(Q^{\pi_0}\) 方法可以更便宜。

## C6. 稳定专家不保证循环路由稳定

取

\[
A=\begin{pmatrix}0.5&2\\0&0.5\end{pmatrix},\qquad
B=\begin{pmatrix}0.5&0\\2&0.5\end{pmatrix}.
\]

两个矩阵各自的谱半径都是 0.5，重复单独使用时渐近稳定。但

\[
BA=\begin{pmatrix}0.25&1\\1&4.25\end{pmatrix},\quad
\rho(BA)=2.25+\sqrt5\approx4.48606798>1.
\]

存在初始状态沿 A、B 交替路径指数扩张。因此单专家 Jacobian 谱半径都小于 1，不能证明切换路径稳定。这是切换系统的经典现象；这里的数值例子为本次构造与计算。[相关研究](https://www.eng.yale.edu/controls/1999/basic.pdf)

另一个更简单的例子：两个常值映射 \(F_A(h)=1\)、\(F_B(h)=-1\) 的 Lipschitz 常数均为 0，交替使用仍产生 1,−1,1,−1 的周期。缺少共同固定点时，压缩性可支持有界性，但不保证收敛到一个点。

**排除标准：**如果增加循环只是导致范数或 loss 爆炸，先解决残差缩放、归一化和状态分布覆盖。不能把稳定化后的精度增益全部归因于更聪明的 Router。反过来，也不能为了证明收缩而让专家全部趋近于常数，再把稳定等同于推理能力。

## C7. 全局匹配中的不可微操作依然可能泄露未来 token

固定第一个位置的专家概率为 (0.40,0.30,0.20,0.10)。两个位置、4 个专家、平均每位置预算 \(K=2\)，离线从全部 8 个分数取 Top-4：

- 后一个位置为 (0.27,0.26,0.24,0.23) 时，第一个位置分到 2 个专家；
- 后一个位置改为 (0.70,0.11,0.10,0.09) 时，第一个位置分到 3 个专家。

两个例子都满足每位置至少 1 个、至多 4 个专家。前缀表示不变而当前路由随后缀变化。可以选择专家输出和读出权重，使这种路由变化实际改变前缀 logits；并非每组参数都必然产生可见变化，例如输出抵消或读出不敏感时可能不变。argTopK 在大部分区域梯度为零，不能保证消除这个**前向信息通道**。

这直接说明应当做 prefix-invariance 测试，而不能用“离散/不可微”作为因果性证明。SeqTopK v2 §3.2 也明确描述 offline 版本依赖未来得分；其脚注关于不可微信息的表述不足以证明前向因果性。[公开版本](https://arxiv.org/html/2511.06494v2)

**精确测试协议：**同一模型 eval 模式、固定随机数与 dropout 关闭、保持 token 0..i 的输入和位置不变，替换 i+1..L 的后缀，逐层比较截至 i 的路由动作和 logits；用 FP32 小模型排除数值非确定性。允许的差异只应来自声明过的浮点误差，不应随被替换后缀系统变化。训练时使用未来得分做 oracle 诊断可以，但最终可部署训练/推理指标必须使用 causal route。

## C8. 对 Online SeqTopK 公开公式预算保证的独立复算

范围：核查 arXiv:2511.06494v2 的式 (7) 与其后的累计预算声称；未运行该论文仓库，也不声称作者已承认问题或其全部实验结果错误。

公开式 (7) 的规则是：第 \(m\) 步从所有历史与当前得分中取 \(mK\) 个最大项，只执行其中属于当前 token 的专家，且不能撤销历史调用。该操作保证的是当前缓存中被选中的项数，不自动约束已经执行的历史总调用数。

合法概率反例：\(E=4,K=1\)。

\[
s_1=(0.40,0.30,0.20,0.10),\qquad
s_2=(0.49,0.48,0.02,0.01).
\]

第一步 Top-1 执行 1 个专家。第二步全前缀 Top-2 为 0.49、0.48，都属于当前 token，故新增 2 个调用。已经执行的总数是 3，大于 \(mK=2\)。文中的 token 下界 1 与上界 \(K+2=3\) 均未排除此例。

**修复方案：**显式保存已花费预算账本，并限制当前调用数 \(q_m\le mK-\sum_{j<m}q_j\)。历史分数仍可作为价值阈值，但最终必须受真实剩余额度约束。修复后应重新评价性能和延迟，因为它会改变原算法的路由分布。这个反例适合形成实现审计或改进动机，但一个公式反例本身不是完整的新算法论文。

## C9. 有顺序的专家互补不能直接套集合 Shapley 解释

取标量状态 \(h_0=1\)，专家 \(A(h)=2h\)、\(B(h)=h+1\)。则 \(B(A(1))=3\)，\(A(B(1))=4\)。相同集合 \(\{A,B\}\) 在不同顺序下产生不同表示，给定 readout 后可以对应不同损失。

因此要研究

\[
S(e,f)=G(e\to f)-G(e)-G(f),\qquad G(p)=\ell(\varnothing)-\ell(p),
\]

并明确顺序、长度、费用与 baseline。若要用集合合作博弈，须先定义集合如何决定顺序（固定、平均、最优等）；这些定义对应不同问题。第一轮宜用状态相关的 pair synergy 或受控路径交换，避免高成本全 Shapley 估计。

## C10. “同样 FLOPs”不等于同样比较

同样调用 2 个专家，Top-2 的并行混合 \(h+\alpha E_i(h)+(1-\alpha)E_j(h)\) 与两次串行 Top-1 的 \(F_j(F_i(h))\) 不是同一个函数类。顺序、归一化次数、residual、路径长度、kernel 数都会变。

必须把两类比较分开：

1. **Router 比较：**专家、循环结构、参数、每轮动作定义相同，只换选择机制。
2. **架构比较：**串行/并行/固定深度之间比较，报告全部结构差异与真实成本。

同样参数量、训练 token 数、训练 FLOPs、推理 FLOPs 和 latency 通常无法同时完全一致。应分别报告 token-matched 主表、compute-matched 确认表和真实推理曲线，而不是只选最有利的单一匹配口径。

## 最小 falsification 清单

| 待检验主张 | 会推翻或限制它的观察 | 之后怎么做 |
|---|---|---|
| 历史含额外有用信息 | 参数匹配 h-only 追平；历史置换无影响 | 删历史，保留价值监督 |
| 多步价值必须规划 | 一步 rollout 恢复全部 held-out 改善 | 用便宜的一步方案 |
| 路由仍有可学习空间 | label oracle 有收益，但标签盲预测无收益 | 检查可观测特征；仍无收益则换目标 |
| 价格缓解容量 | 平均均衡、每轮仍超载或振荡 | 加可行 dispatch；价格只作偏好 |
| 收缩解释有效推理 | 收缩增强但 NLL/任务精度下降 | 分离稳定性与表示能力 |
| 省调用即加速 | GPU latency 无改善 | 转到 group/depth bucketing 或计算质量论文 |
| 全局路由可因果部署 | 固定 prefix 换 suffix 改变前缀 logits | 换 prefix-only 规则重训/重评 |
| 资源预算确有保障 | 真实调用账本超过 prefix/请求预算 | 硬约束合法动作并补做性能比较 |
